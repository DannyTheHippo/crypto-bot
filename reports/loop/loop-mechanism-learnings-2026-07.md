# Loop-Mechanism Learnings — 2026-07 (Y1)

This report is about the loop mechanism, not the application: what the discrete 3x-daily pass model, the WATCH grammar, the soak digests, and the audit layers actually detect, what they structurally cannot, and which amendments Y2-Y4 adopt as a result. Sources mined: `reports/loop/LOG.md` (Passes 0-34, through 2026-07-18), `reports/loop/state.md` (including the W4-W6 / WATCH-R8 era LOG.md does not cover), `w6-digests.txt`, `a0-analysis-2026-07-20.md` (A0), `reports/audit-2026-07-cleanup.md` (W4 audit), and the standing memory files. Coverage boundary: LOG.md ends at Pass 34, so WATCH-R8-6/7/8, the W6 collector duds, and the A0 amendments are characterized from state.md and the digest file; the 40-minute phantom-bug incident behind the `date -u` rule is recorded in neither LOG.md nor state.md and must be sourced from session records before it is lost (state.md:666-668 codifies only the rule).

## A. What the pass mechanism caught vs missed — and why

The pass model is a delta-reasoning instrument over exported signals. Everything it caught, it caught by comparing counters across time; everything it missed was either unexported, semantically wrong-but-active, or faster than the inter-pass gap.

What it caught:

- Silent outages via delta reasoning — but at inter-pass latency. The 8.2h candle-stream stall ran behind fully green surface signals (health 200, ticker alive, marks updating) and was found only when Pass 30 compared decides/hour (steady 20/hr, then nothing after 16:00:10Z) and a 6h prescreen increase of zero (LOG.md Pass 30, 2026-07-17, Bug A). Detection latency equals the gap: ~8.2h dead, ~-$4.5 realized (state.md:838-847).
- Subtle defects via metric-shape signatures, not log lines: churn = placed high with zero skipped_existing (LOG.md Pass 25: placed=15/qty_cancel=14/0 skipped_existing); build-and-discard = counter increments with no matching DB rows (LOG.md Pass 27); attribution leak = a new `unknown` bucket growing while a version bucket shrinks (LOG.md Pass 33 Bug E: v1 22 to 18, unknown=5).
- Pre-registered WATCH signatures converting deploys into experiments: the Phase-2 WATCH ("an orphan/qty_cancel spike = ...") caught the venue-TP churn the moment counters were read (state.md:166-175, 919-925, fix debef0f); P8d WATCH 2 went RED on exactly the phantom-position failure it was written to guard (LOG.md Pass 30 Bug B); Pass 26 caught venue-stop non-engagement purely from pre-registered absence-of-expected-signal (state.md:386-396).
- Fix verification across restarts, because Prometheus retains history the app loses: Pass 13 answered the Pass-12 reflection-timeout question with an instant `--time` query against the prior boot's series (LOG.md Pass 13, "THE DISCRIMINATOR").
- Burst pathologies — but only once the hourly digest existed: WATCH-R8-8's reflection hot loop (91 Opus calls / ~$2.30 in 46 min) was caught in ~1-2h by the W6 cycle, fix deployed 03:14Z (state.md:616-633). A 3x-daily pass would have multiplied the cost.
- Premature promotion, via layered soak-clock discipline: the L0-to-L1 shorts pre-auth was blocked, cleared, re-BLOCKED at Pass 30, and re-cleared only after 351 consecutive CLEAN reconcile passes on the healed boot (state.md:394-405, 851-852, 1139-1142).

What it missed, and why:

- Absence-of-signal reads as health. Every Prometheus alert rule was dead since first boot (rule_files glob matching nothing is not an error); no pass noticed until Pass 6 hit `/api/v1/rules` directly and got `{"groups":[]}` (LOG.md Pass 6). Same class, worse instance: WATCH-R8-7's reconcile false-halt suppressed every spot decide for ~a day while three stacked observability defects (engage() logs nothing, halt suppression logs nothing, `/health/ready` hardcodes killSwitchState RUNNING) kept every surface green — a pass reading a 24h log window with no liveness deltas had nothing to see (state.md:596-615, 669-671).
- Single-emission failures. A FATAL client latch emitted one warn line — no gauge, no alert — and the lane died silently for ~1h; only a continuously tailing reader could see it (LOG.md Pass 5). WATCH-R8-6's wedge-to-OOM chain (36 recreations in ~35 min) was caught live only because a session was watching; a discrete pass would have arrived after Docker's auto-restart and seen RestartCount=1 (state.md:577-595, 671-673).
- Semantic wrongness behind green activity. Passes verify greenness and motion, not sidedness or effect: perp-short protection was fully inverted (absent field silently meant long) behind green tests and normal order flow (audit-2026-07-cleanup.md line 17); the P2 expert seed playbooks never went live for the entire v2 era because a pre-existing DB row shadowed the seed const, and deploy verification checked boot health, not semantic effect (state.md:728-733, XA3).
- Dead fail-closed paths and fail-open polarity defects. A dead safety path is observationally identical to a healthy quiet one: missed-fill backfill and the FILL_FOR_UNKNOWN_ORDER halt could never fire, latent through weeks of green passes until the W4 code audit (audit-2026-07-cleanup.md line 18); three fail-open/coercion defects (promotion gate, VENUES refusal, z.coerce.boolean) emitted zero runtime signal and survived every pass (audit lines 22, 24, 25). Only adversarial code reading reaches this class.
- Wrong conclusions propagating as trusted facts. Pass 14/17's "count-preserving, self-fading" straddle model was falsified by Pass 18 (a permanent per-symbol freeze); Pass 27's venue-rejection mechanism was overturned by Pass 28's live probe (adapter destructuring bug) (LOG.md Pass 18, Pass 28). Even the deep-analysis layer fabricates: A0's "llm_usage only reflection rows" was a query mis-read caught only during XA4 implementation (state.md:738-740).
- Silent not-fired branches. Reflection dormancy ran 3+ days because a close-that-evaluated-but-did-not-fire left no metric or log; Pass 24 needed manual boot-timeline forensics (LOG.md Pass 24, backlog #53).
- Metric-visible anomalies normalized as noise. Universe-wide STALE_DATA blackouts were observed "every ~10 min" across passes and only the W4 audit root-caused the global 350ms resubscribe queue (audit-2026-07-cleanup.md line 26). The digests recorded 46min-2h uptime churn in every check; no pass applied "uptime should be monotonic between deploys" until A0 cited those exact lines (w6-digests.txt:4,70,134; A0 finding 9).
- Ratios nobody computed. Consult starvation (1-3 wakes/day vs 10-20 design intent) was computable from every cycle-1 digest — skipped_scheduled climbing 80 to 432 against an empty [consults] section — yet it took A0's 1.47M-token analysis to state it (w6-digests.txt:53-358; A0 finding 1). Empty `plan_json` on every v2 consult had no watcher at all: a data-capture defect with zero log signature is invisible to any log-window pass by construction (A0 finding 6, XA4).
- Its own instruments. Log-grep soak verdicts produced a factually wrong "did not HALT" claim that metrics refuted — the HALTED_DEGRADED engage line sat outside the grep window (state.md:1091-1110, S6b addendum); five consecutive hourly digest checks returned all-empty log sections while containers read healthy, reproducing the zero-delta signature inside the watching instrument itself, spanning the exact window R8-8 fired (w6-digests.txt:193-354).

## B. Watching patterns: earned their cost vs failed

Earned:

- Keyed live probes before trusting any venue endpoint (the #54 pattern). Three consecutive wrong inferences in one defect chain — bare arrays vs `{orders}`, venue market ids the unified filter can never match, string algo timestamps — each corrected by a probe that code reading had gotten wrong (LOG.md Pass 28, Pass 29 item 2, S6b; state.md:870-876, 1105-1114). Mocked tests cannot reach real demo-venue shapes.
- Provenance-before-interpretation. docker inspect StartedAt/RestartCount + bootId + git timestamps before reading any counter (LOG.md Pass 9); skipping it fabricates evidence — `increase()` over multi-boot windows produced ~11.8k spurious mismatches via counter-reset extrapolation (LOG.md Pass 24).
- Pre-registered WATCH grammar with named expected AND named defect outcomes. Signature-carrying WATCHes resolved decisively (first-mint watch, LOG.md Pass 16; P8d items, state.md:376-405) while open-ended ones rotted — WATCH-V2-3 was never resolved and A0 later found `plan_json` empty on every v2 row: "X6-X8 would have been built on nothing" (state.md:513-514, 689-690).
- Independent-derivation cross-checks as the measurement-trust gate. Hand-priced token math matching the DB gauge to the cent cleared stop-condition suspicion and caught the dashboard's ~1.5x cache-blind undercount when they diverged (LOG.md Pass 10, Pass 17).
- Post-deploy soak against live traffic. It falsified designs unit tests approved: the HOST=127.0.0.1 blind-scrape regression (LOG.md Pass 0) and Pass 7's own fresh ReconcilerStalled expression, re-keyed same pass (LOG.md Pass 7, 378f88b).
- The every-pass $0 harness probe — with the placement lesson: the offline eval harness rotted RED ~1 day because nothing ran it, and the probe first landed in a playbook section that ship-nothing passes skip, exactly where silent rot hides, before moving into the evidence sweep (LOG.md Pass 10 addendum, Pass 11).
- Standing verdicts as binding negative results (price-TA EMPTY over 4,562 backtests, funding-carry NO-GO 0/126, demo fees flat 10bps) — passes cite instead of re-deriving dead ends (state.md:1202-1230).
- Data-gated pre-authorizations. P0b fired exactly at its stated trigger (N=25, Pass 34), produced its report, and was marked CONSUMED — a clean grant-to-retirement lifecycle without scope drift (state.md:250-258).
- Fix-in-the-finding-pass bug routing (owner decision 2026-07-16): Passes 25, 30, 32, 33 each shipped reviewed, gated, deployed fixes inside the finding pass; the defect queue never rotted (state.md:43-47).
- Adversarial finder/two-refuter review. W4 caught 17 confirmed defects that weeks of green passes and 2,440 green tests missed, while the refutation stage filtered at least 4 false positives before any fix (audit-2026-07-cleanup.md lines 4-11, 52-57); P7e/P7f found the OMS blind to the perp algo rail (state.md:328-344).
- Cycle-2 digest hardening: per-container "(N json lines in window, read try 1)" read proofs and a "[bootIds in window]" section made an empty section verifiable instead of ambiguous (w6-digests.txt:433, 452, 501-503); writing the expected post-fix observable into the START banner let GREEN be read directly off named counters and closed the soak early (w6-digests.txt:423, 539-540, 556).
- Digests as a durable evidence archive even for un-acted signals: the tolerated 1008 mass-close churn in every window became the retroactive evidence base for XA6/X2 sharding (A0 finding 8; state.md:577-595).

Failed:

- Negative log reads, categorically. `docker logs --since` returns empty across rotated segments and after Docker Desktop restarts; reads crossing a rotation boundary truncate silently; recreates delete prior boots' segments (LOG.md Pass 18 ops gotcha, Pass 23; state.md:640-642). This "silently voids negative grep evidence" and produced the false S6 "did not HALT" verdict (state.md:1091-1110).
- Log channels themselves. Production AgenticStrategy ran on NOOP_LOGGER, so every warn was invisible (LOG.md Pass 28, backlog #55); single-file bind mounts served stale/truncated views after replace-by-rename (LOG.md Pass 8, Pass 30); a committed NUL byte made grep classify a source file as binary, masquerading as absent evidence until Pass 19 root-caused it (LOG.md Pass 19).
- The collector as its own failure surface. The first W6 collector was a dud (1 line in 8h), misdiagnosed via an alphabetical `ls|tail` miss; the replacement restarted ~T+1h; cycle 2 silently skipped its 04:15/05:15 checks between two START banners and nothing remarked on the gap (state.md:640-645; w6-digests.txt:1, 423, 491).
- Digest sections with no signal contract. [consults] produced zero data in every check of the entire soak — the exact field A0's top findings needed (w6-digests.txt:15-526); [funding] never matched; [portfolio] duplicated verbatim; [scan] truncated mid-JSON (w6-digests.txt:22, 13-14, 21). The errors/warns filter inverted signal and noise: 1008/keepalive churn dominated as pseudo-signal while the actual R8-8 precursor — "skipping mint, trigger preserved" re-firing every ~15 min — sat present for hours and was never escalated (w6-digests.txt:24-28, 18-19, 84-85).
- Schedule collisions with deploy sessions. Passes 9, 14, and 18 each swept minutes of data behind a redeploy, and the two-empty-passes cadence rule needed manual "timing artifact, not backlog exhaustion" overrides (LOG.md Passes 9, 14, 18; empty-counter reasoning at Pass 10).
- Treating deploys as neutral. Container recreates wiped in-memory activePlan (bare positions billing ~$1/day/symbol, LOG.md Pass 20), reset reflection primes across at least five boots (LOG.md Pass 24), and reset process counters — every redeploy is a perturbation the next sweep must model.
- Interim containment postures recorded without metric confirmation. The Bug B "lane left running, phantom exits all REJECT" posture was recorded as safe while the drift axis was actually HALTing the lane the whole time (state.md:1073-1080, 1136-1137).
- A static playbook against a moving stack. By 2026-07-19 it still cited retired artifacts — agentic_prescreen_total, expectancy-ladder MAY-knobs, a $5/day breaker — after the v2 cutover deleted or replaced all three (state.md:673-675 vs 479, 509).
- Discrete passes needing an episodic deep dive as compensation. A0's 6-analyst / 1.47M-token run surfaced findings that were cheap deterministic checks all along — starvation ratio, empty plan_json, three-ledger divergence, stale specs — evidence of missing standing invariants, not missing intelligence (a0-analysis-2026-07-20.md header; findings 1, 2, 6, 7).

## C. Defect-class signatures every future pass evaluates FIRST

1. Zero-delta-while-green. Observable: green health endpoints, healthy containers, kill_switch RUNNING — and zero decide/journal/counter deltas over the window. Naive miss: absence of errors reads as quiet health; the same frozen shape has been benign (LOG.md Pass 10, prescreen doing its job) and catastrophic (LOG.md Pass 30 Bug A; state.md:596-615 R8-7, where `/health/ready` hardcoded RUNNING). Probe: demand positive watermark deltas from multiple independent counters (prescreen/heartbeat/reconcile/decides-per-hour) against a time anchor; read the kill-switch METRIC and the reconciliations result distribution, never `/health`.
2. Row-count-window shrink. Observable: an evidence consumer's verdict changes after row volume grows (abstain false-positive, unreachable promotion floor, shrinking attribution). Naive miss: the consumer's code is unchanged and green; the data outgrew its `recent(N)` window. Thrice burned: #39, Bug C (cfb2ed3), Bug E (309bbfc) (state.md:455-461; A0 finding 7 makes epoch-bounded reads mandatory on X8). Probe: on any new stats consumer, check window semantics first — shared `recent(N)` walks are forbidden.
3. Silent-catch/park. Observable: nothing — a pending-forever promise, an in-memory health enum nothing exports, a swallowed hot-path throw. Naive miss: sweeps hunt error lines; this class emits none (LOG.md Pass 30 Bug A watch* futures; Pass 32 Bug D "same silence class"; Pass 27 line 1309; bare `{"type":"REJECT"}` events, state.md:1072-1073). Probe: hunt state-set-but-never-emitted seams; every new loop/gate needs its failure path logged AND metric'd before enable.
4. Structurally invisible divergence axis. Observable: none by construction — Bug B's phantom perp position was invisible to ALL monitoring because nothing reconciled positions on that venue (state.md:1052-1063). Naive miss: passes check the reconcilers that exist, not the axes that lack one. Probe: on any new rail/venue/state axis, enumerate its reconciliation consumer or declare it unmonitorable — declaration forces the decision.
5. Venue/ccxt shape divergence. Observable: a working code path built on a declared shape that live returns differently. Four incidents from trusting declared shapes: describe() under-reporting watch* (359e4a7), bare array vs `{orders}` (25563bc), spawned id in actualOrderId (333db28), string algo timestamps (bd1cab2) (state.md:369-376, 872-876, 1110-1114, 1130-1132). Naive miss: mocked tests encode the assumed shape and pass. Probe: keyed live shape probe before any code depends on a new endpoint (the #54 pattern).
6. Boot-scoped counters masquerading as cumulative. Observable: a counter "drops" (190 to 72, 432 to 23) across the window. Naive miss: cross-cycle deltas silently go wrong after any restart; A0 conceded the counters' boot epoch was unknown (w6-digests.txt:117 vs 178, 358 vs 474). Probe: pin every counter read to a bootId before trusting a delta; use Prometheus `increase()` only within a single boot's span.
7. Three-ledger divergence. Observable: gate metrics, the consult journal, and actual API spend disagree (24 forced_fallback + 2 forced_move vs ONE journaled consult vs $2.16 spent, w6-digests.txt:359-362, 405-407; A0 finding 2, XA1). Naive miss: each ledger alone looks self-consistent. Probe: reconcile all three before tuning any cadence knob; treat divergence as defect-until-proven-undercount.
8. Attempt-level fail-open budget gate. Observable: post-breach blackout — with_tokens=0 every hour after a shared pool zeroes. Naive miss: the breaker "worked" (it stopped spend) while converting one overshoot into same-lane starvation; mid-attempt calls failed OPEN by design ($1.49 admitted, finished at $2.48 past the $1.50 stop; A0 finding 5, XA2). Probe: check gates for pre-attempt reservation vs start-only checks; alarm on pool-zeroed states.
9. Negative-read voids. Observable: an empty grep/log/promtool result. Naive miss: empty is taken as "nothing happened" — but `--since` breaks after daemon restarts, rotation truncates silently, this shell's grep alternation silently fails, promtool denials are intermittent (state.md:640-642; memory crypto-bot-live-data-access.md:18-33; LOG.md Pass 18). Probe: every empty read is void unless paired with a positive control known to return data, plus a bootId-matched `--tail` probe.
10. Unanchored log-time forensics. Observable: a defect narrative built from timestamp comparison with no wall-clock anchor. Naive miss: ad-hoc anchoring fabricated a 40-minute phantom-bug chase (incident not in state.md — codified only as the Y4 `date -u` rule, state.md:666-667; precursor discipline: LOG.md Pass 22's window_days anomaly-chase). Probe: `date -u` anchor before any timestamp comparison; verify the clock before the code.
11. Fail-open polarity and config coercion. Observable: nothing at runtime until the bad branch is exercised. Naive miss: observation-based passes cannot see an un-exercised branch; three instances (promotion gate open on missing funding, VENUES-empty refusal open, z.coerce.boolean turning "false" into enabled) survived every green pass (audit-2026-07-cleanup.md lines 22, 24, 25). Probe: adversarial polarity audit on every gate — state the failure direction and test the bad branch.
12. Non-consuming-trigger hot loop. Observable: attempt-started counters racing ahead of fire stamps; cost/burn spikes in minutes. Naive miss: each individual firing looks legitimate; only the rate is wrong, and 3x-daily latency multiplies the burn (R8-8: 91 Opus calls in 46 min because failure exits restored lastAttemptAt, state.md:616-632). Probe: compare attempt-started vs consumed-stamp counters per window; burst-rate alarms on spend counters.

## D. Design amendments adopted into Y2-Y4

Y2 — deterministic health sweep:

- Watermark-delta based, metrics/DB-first: every vital sign is a current counter compared against a timestamped prior reading; state-only greens are never accepted; Prometheus and durable tables outrank logs (survives restarts, immune to NOOP_LOGGER) (LOG.md Pass 30 detection; S6b metrics-not-logs; state.md:662-665).
- Provenance stamps per lane: bootId, RestartCount, git tip recorded before any counter is interpreted; all counter deltas bootId-pinned (LOG.md Pass 9; w6-digests boot-scoped counter class).
- Open with host-state: pmset/uptime/kern.boottime and a duty-cycle quantification before interpreting any gap; sleep/wake edges are the highest-risk windows (memory crypto-bot-host-sleep-duty-cycle.md; R8-6/R8-7 both rooted in the sleep window, state.md:577-578, 601-602).
- Empty/negative reads are sweep FAILURES requiring a positive control, never passes — the "hard Y2 requirement" state.md itself binds (state.md:640-643).
- Named invariants from A0: per-bootId three-ledger reconciliation, rate-vs-design-intent ratios (consults/day vs band, entries/day, promotion-date drift), durable-record field-population checks (plan_json non-empty, llm_usage kind=consult), and the X9 execution alarms (consecutive-REJECT, fill-to-terminal latency, repeated-noop, stuck-NEW) (A0 X9 items 1-4, XA4, XA5).
- Named defect-class checks: the § C list runs first, by name — zero-delta, window-shrink, unknown-bucket, silent-park (LOG.md Pass 33 Bug E; state.md:596-615).
- Execution environment baked in: sandbox-disabled validation with the orchestrator running the authoritative gate (memory crypto-bot-sandbox-validation.md); never `cd` into the repo, `git -C` + `corepack pnpm --dir` + PATH-prefixed node (memory crypto-bot-fnm-node-gotcha.md); artifact verification (git status + Glob) after every subagent dispatch before recording results (memory agent-claim-verification.md, subagent-early-stop-pattern.md).

Y3 — standing hourly digest collector:

- Justified by measured blind-window cost: 8.2h (Bug A), ~10h host-dark (LOG.md Pass 17), ~1h latch (LOG.md Pass 5) all exceeded any pass's reach; R8-8's ~1-2h catch is the positive case (state.md:616-633).
- The collector carries its own liveness contract: a heartbeat line every interval so "no output" is distinguishable from "nothing happened"; startup self-verification by reading back a sentinel; discovery by mtime, never name ordering; self-monitoring of its own check cadence (the missing 04:15/05:15 checks) (state.md:642-645; w6-digests.txt:1, 423, 491).
- Computes per-cycle counter DELTAS itself — the R8-8 catch mechanism, currently done by the human reader (w6-digests.txt:316 vs 361).
- Per-section expected-activity floor: an empty capture is an alarm, not a blank (the five all-empty checks, w6-digests.txt:193-354); keeps cycle-2's line-count/read-try/bootId annotations; fixes the never-populated [consults] extractor; drops dead [funding]/duplicate-[portfolio] weight; Prometheus counters as the log-independent backstop.
- Never `docker logs --since` across restarts; passes rehydrate from digest history, never a raw 24h log window — the raw-window model is what made R8-7 invisible (state.md:664-666, 670-671).

Y4 — playbook v3:

- The playbook is code that rots: per-section provenance dates plus a standing re-verify-against-current-code rule (LOG.md Pass 2's rule pruned two stale backlog items; in-pass repairs at Pass 3 and Pass 11); purge the stale v2-era citations (prescreen counter, ladder knobs, $5 breaker — state.md:673-675).
- Verify-before-build / verify-before-cite: every operational claim pinned to a currently-greppable artifact with a last-verified date; spec-vs-stack drift is a demonstrated recurring class (A0 finding 7: X6's "new knob" live since 07-08, X3/X5 duplicating live feed blocks; A0 Risks on unverified load-bearing citations).
- INCIDENT-FIRST gate on any sweep alarm, and the `date -u` wall-clock forensics discipline as a hard pre-step before any timestamp comparison (state.md:666-668); source the phantom-bug incident narrative from session records before it is lost (it exists nowhere in state.md).
- WATCH grammar as the core primitive, tightened: every WATCH carries an explicit expected-positive signature, a named defect outcome, and a resolution deadline/owner-pass — signature-carrying WATCHes resolved decisively; open-ended V2/R8 sets rotted unobserved (state.md:166-175, 376-405 vs 507-525, 565-576).
- An N-recurrences-triggers-root-cause rule so metric-visible anomalies stop being normalized as background noise (the ~10-min STALE_DATA blackouts, audit-2026-07-cleanup.md line 26; the unflagged uptime churn, w6-digests.txt:4,70,134).
- Loop-shipped fixes get continuous soak observation, not just a green suite — the W4 reconciliation fix minted R8-7 while 2452/2452 tests passed (state.md:599-604); every automated remedy carries a cap/cooldown that fails LOUD to the next safety rung (R8-6 seam v2, state.md:577-595).
- Encode the 2026-07-17 full delegation: all demo money-path work is loop-domain; the live flip is the only human gate (memory crypto-bot-delegation-2026-07-17.md; state.md:666-668).
